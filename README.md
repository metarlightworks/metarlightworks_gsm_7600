# METARLightworks GSM 7600 Firmware

Firmware for the METARLightworks GSM cellular lamp using the LilyGO T-SIM7600G / SIM7600G-H board.

OTA is Wi-Fi only.

The public firmware should not contain the private AVWX API key. Production devices should receive the key from the factory/provisioning loader and store it in ESP32 NVS.
